# زاجل

برنامج ماك لإدارة نسخ الهاتف والملفات والسحابة، مع مساعد ذكي داخلي. واجهة عربية.

## التثبيت على ماك جديد
```
git clone https://github.com/zerouno2345seis-oss/zajel.git
cd zajel
bash install.sh
```

## التحديث
من داخل زاجل: المساعد ← الإعدادات ← «تحديث البرنامج».

## المزامنة بين الأجهزة
الإعدادات والذاكرة تُزامَن عبر مستودع **خاص** بحسابك (`zajel-data`)، ولا يُرسل شيء إلا بضغط «زامن الآن».
يلزم تسجيل الدخول مرة واحدة: `gh auth login`.
